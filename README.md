# 理头发日历

一个手机优先的离线 PWA：打开即可按藏历日期判断是否适合理头发，并可把未来吉日导出为 `.ics` 导入 iPhone / Android 日历。

## 当前能力

- 自动把公历日期换算为 Phugpa 藏历日期。
- 首页大字显示所选日是否「大吉 / 宜剪 / 慎择 / 不剪」。
- 一页式月历，点击任意日期即可查看当天详情。
- 显示对应农历和常见藏传殊胜日。
- 导出未来一年宜剪日为手机日历文件。
- 为所选日期单独生成日历事件。
- 离线缓存。通过 HTTPS 打开一次并添加到手机主屏幕后，出门断网也能用。

## 手机内置使用

不要把 `127.0.0.1` 或局域网 IP 当正式入口，那只是电脑开发预览。正式使用要把这一整个静态目录部署到一个公网 HTTPS 地址，例如 GitHub Pages、Cloudflare Pages、Netlify、Vercel 或自己的域名。

部署后在手机 Safari 打开那个 HTTPS 地址，点分享按钮，选择「添加到主屏幕」。之后它会像一个手机 app 一样从主屏幕打开，并使用已缓存的本地代码和日历算法，不依赖家里的 Wi-Fi。

## 本地运行

```bash
python3 server.py
```

打开终端显示的本机地址，例如 `http://127.0.0.1:8001`。本地运行只用于电脑预览和调试，不能作为出门使用的手机入口。

## 日历联动说明

移动浏览器没有读取系统日历的通用权限，所以应用采用 `.ics` 文件联动：点「导入日历」生成未来一年吉日，点「添加所选日到日历」生成单日事件，然后交给系统日历导入。

藏历换算采用本地 Phugpa 算法，整理自 `@hnw/date-tibetan` 的 MIT 实现，并参考 Svante Janson 的 Tibetan calendar mathematics。实际修学使用时，如寺院历书或依止处给出的日期不同，请以依止处为准。
